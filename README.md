# SpagetiKnot

AI가 생성한 코드의 흐름을 빠르게 파악하기 위한 VSCode 익스텐션.

## 왜 만들었나

AI 코딩 도구가 대량의 코드를 빠르게 생성하지만, 결과물의 함수 간 호출 관계와 이벤트 흐름을 사람이 파악하는 데는 시간이 걸린다. SpagetiKnot은 워크스페이스의 함수 선언과 호출 관계를 자동으로 분석하여 **인터랙티브한 플로우 다이어그램**으로 보여준다.

목표는 단순하다: **"이 함수가 어디서 호출되고, 무엇을 호출하는가?"** 를 코드를 읽지 않고도 시각적으로 파악할 수 있게 하는 것.

## 기능

### 함수 분석
- 워크스페이스 전체의 함수 선언을 자동 탐지 (JS/TS, Python, Go, Rust, Java, C#, C++)
- 파일 간 함수 호출 관계를 분석하여 caller → callee 엣지 생성
- 함수 파라미터와 호출 인자를 추출하여 변수 흐름 추적
- 제어문(`if`, `for`, `while` 등)을 함수로 오탐하지 않음

### 인터랙티브 캔버스
- **노드 드래그**: 함수 노드를 자유롭게 배치. 드래그 시 소속 파일 그룹 박스가 자동 확장
- **파일 그룹 드래그**: 그룹 헤더를 잡고 드래그하면 내부 노드 전체가 함께 이동
- **파일 그룹 리사이즈**: 그룹 박스 외형선에 마우스를 가져가면 커서가 변경되고, 드래그로 크기 조절
- **줌 & 패닝**: 마우스 휠로 줌, 빈 공간 드래그로 패닝
- **함수명 검색**: 상단 검색창에 입력하면 비매칭 노드/엣지가 흐리게 처리
- **더블클릭 → 소스 이동**: 노드를 더블클릭하면 해당 파일의 해당 라인으로 이동
- **파일별 색상 구분**: 파일마다 고유 색상으로 소속 구분

### 클릭 하이라이트
- **노드 클릭**: 선택된 노드가 흰색 글로우로 강조, 연결된 노드는 금색 글로우, 나머지는 페이드
- **엣지(연결선) 클릭**: 클릭하면 팝오버가 나타나 해당 호출에서 어떤 변수가 넘어가고(args), 어떤 파라미터로 받는지(params) 표시
- 빈 공간 클릭으로 선택 해제

### 파일 그룹 내부 레이아웃
- 각 파일 그룹 박스 우상단의 토글 버튼으로 내부 함수 배치 변경
  - `|` 1열 (기본)
  - `||` 2열 그리드
  - `|||` 3열 그리드

### 대시보드 (팝오버)
- 상단 툴바의 "Dashboard" 버튼으로 토글
- 자유롭게 드래그하여 위치 조절 가능
- **파일 그룹 레이아웃**: Single column / Horizontal row / Compact / Stacker (2행 오프셋 배치)
- **뷰 컨트롤**: Fit to screen / Reset zoom
- **파일 목록**: 워크스페이스 내 파일별 색상 점 + 함수 개수 표시

### 비동기 로딩
- 커맨드 실행 즉시 웹뷰가 열리고, 인덱싱은 백그라운드에서 비동기 실행
- 인덱싱 완료 후 자동으로 그래프 렌더링
- 하단 상태바에 SpagetiKnot 버튼이 익스텐션 활성화 즉시 표시

## 사용법

1. 이 프로젝트를 VSCode에서 열고 `F5`로 Extension Development Host를 실행한다.
2. 테스트 대상 프로젝트를 열고, 커맨드 팔레트(`Ctrl+Shift+P`)에서 **SSDF** 또는 **SpagetiKnot**을 검색하여 실행한다.
3. 또는 하단 상태바의 **SpagetiKnot** 버튼을 클릭한다.
4. 현재 탭에 플로우 다이어그램이 나타난다.

## 프로젝트 구조

```
src/
├── extension.ts    # 익스텐션 진입점, 커맨드 등록, 비동기 인덱싱
├── parser.ts       # 정규식 기반 함수 선언 탐지 + 파라미터 추출
├── references.ts   # 함수 호출부 탐색, caller→callee 엣지 + 인자 추출
└── webview.ts      # Canvas 기반 플로우 다이어그램 + 대시보드 렌더링
```

각 소스 파일 상단에 함수 테이블이 있다. 파일을 열면 해당 모듈의 함수 목록과 호출 관계를 바로 확인할 수 있다.

## 개발

```bash
npm install
npm run compile   # 또는 npm run watch
```

`F5`를 누르면 Extension Development Host가 실행된다.
